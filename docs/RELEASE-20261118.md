# v2.7.0 production candidate, November 18, 2026

Owner requested publication of reviewed new features for real-user testing, accepting incomplete exhaustive testing. This is a scoped promotion, not a DEV-tree replacement.

## Included
- Device-local doubles tournaments at `/local/brackets/`, linked from scoring. Named players may play before payment or check-in; paid/check-in remain organizer tracking fields.
- Local bracket drawing, game overrides, scorer integration, result receipts, guarded corrections and finals from the existing DEV implementation.
- Approved dragon-free Brisket Burt closure artwork, descending displayed targets without changing saved target order, and consistent game-card titles.
- Root cache `blakeout-v65-local-tournaments-20261118` includes the local tournament dependencies.

## Preserved boundaries
- Ordinary production roster Firebase implementation, configuration and rules unchanged. Local tournament scoring does not initialize cloud roster sync.
- Production cloud Accounts and cloud Brackets remain gated. No OAuth, backend, email, identity or sharing rollout.
- Existing ordinary/DEV save keys unchanged. Production local tournaments use `blakeout_local_tournaments_v1` and `blakeout_local_*` scorer keys, separate from DEV local data. No automatic migration or deletion.
- Bullshit remains available for local scoring, not lifetime/shared stats or tournaments.
- Tournaments exist only in this browser/device; clearing browser storage loses them. This is not backup or cross-device sync.
